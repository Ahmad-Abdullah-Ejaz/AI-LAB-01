# AI Lab 01 - Python Basics & Basic Algorithms

This repository contains my work for Lab 01 of the Artificial Intelligence course. The lab focuses on revising core Python concepts (data types, conditionals, strings, lists) and writing simple search and duplicate detection algorithms from scratch.

---

## Folder Structure

```text
├── basics/
│   ├── 01_io_and_syntax.py          # Input/output and basic syntax
│   ├── 02_data_types.py             # Numbers, casting, and complex types
│   ├── 03_conditional_statements.py # If-else and comparison checks
│   ├── 04_string_operations.py      # Quotes, indexing, and slicing
│   └── 05_list_operations.py        # List slicing and loops
│
└── algorithms/
    ├── 01_linear_search.py          # Linear search in a single list
    ├── 02_sequential_search.py      # Searching across two lists sequentially
    ├── 03_common_element_search.py  # Finding common elements between two lists
    └── 04_duplicate_detection.py    # Checking for duplicate items
